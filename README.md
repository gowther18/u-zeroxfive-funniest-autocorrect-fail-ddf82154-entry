One autocorrect fail, 69 characters, one line:

> Sorry I'm late, I got stuck in a threesome - I mean traffic. TRAFFIC.

The joke: the most ordinary excuse in the world ("stuck in traffic")
arrives with one word swapped for something wildly, embarrassingly
different, and the sender's panicked all-caps correction ("TRAFFIC.")
is the tell of a real person caught by their own phone. The slip is
clear on first read, the wrong word is specific and surprising, and
the line reads as a genuine frantic text, not a written joke.

## Run it

```sh
python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`/output/entry.txt`), byte-identical on every run. Python 3.13,
standard library only, no network.
